భారతీయ మరియు ప్రపంచ స్టాక్ మార్కెట్లకు సంబంధించిన వార్తలు, విశ్లేషణ, కార్పొరేట్ చర్యలు మరియు ప్రత్యక్ష నివేదికలను పూర్తిగా తెలుగులో అందించే పర్సనల్ ఫైనాన్షియల్ న్యూస్ డ్యాష్బోర్డ్.

ప్రతి రెండు గంటలకు ఒకసారి అధికారిక మార్కెట్ మూలాలు (NSE, BSE, SEBI, RBI, Moneycontrol, Economic Times, LiveMint, Business Standard, CNBC, MarketWatch, US Federal Reserve మొదలైనవి) నుండి వార్తలను సేకరించి, డూప్లికేట్లను తొలగించి, AI (Groq) ద్వారా తెలుగులో సారాంశం, సెంటిమెంట్ మరియు మార్కెట్ ప్రభావ విశ్లేషణలను రూపొందించి స్టాటిక్ వెబ్సైట్గా ప్రచురిస్తుంది.

## 🏷️ మార్కెట్ ప్రభావ లేబుల్స్ (Market Impact Labels)

- 🟢 **సానుకూలం (Positive)**: మార్కెట్ లేదా సంబంధిత షేర్లకు సానుకూల ఊపునిచ్చే పరిణామం
- 🔴 **ప్రతికూలం (Negative)**: అమ్మకాల ఒత్తిడికి కారణమయ్యే అంశం
- 🟡 **తటస్థం (Neutral)**: మార్కెట్పై పెద్దగా ప్రభావం చూపని సాధారణ పరిణామం
- 🟣 **మిశ్రమ ప్రభావం (Mixed)**: ఒక రంగానికి సానుకూలంగా, మరొక రంగానికి ప్రతికూలంగా ఉండే వార్త

## 🚀 లోకల్ రన్ సూచనలు (Local Execution)

### 1. డిపెండెన్సీలను ఇన్స్టాల్ చేయడం
```sh
pip install -e .
# లేదా
pip install feedparser requests yfinance pytest
```

### 2. ఎన్విరాన్మెంట్ వేరియబుల్స్
`.env.example` నుంచి `.env` ఫైల్ను క్రియేట్ చేయండి:
```sh
GROQ_API_KEY=your_groq_api_key_here
NEWS_TZ=Asia/Kolkata
```
*(గమనిక: `GROQ_API_KEY` లేకపోయినా అంతర్నిర్మిత రూల్-బేస్డ్ తెలుగు ఇంజిన్ ద్వారా సైట్ పూర్తిగా బిల్డ్ అవుతుంది)*

### 3. కమాండ్లు
```sh
# వార్తలను సేకరించి, తెలుగు విశ్లేషణను జతచేసి, సైట్ను నిర్మించడం:
$env:PYTHONPATH='src'; python -m news_bot.cli run --data-dir data-store --out _site

# లోకల్గా ప్రివ్యూ చూడటం (http://localhost:8000):
$env:PYTHONPATH='src'; python -m news_bot.cli serve --out _site

# అన్ని న్యూస్ సోర్స్ల హెల్త్ చెక్:
$env:PYTHONPATH='src'; python -m news_bot.cli sources

# టెస్టులను రన్ చేయడం:
python -m pytest
```

## 🌐 GitHub Pages డెప్లాయ్మెంట్ (Deployment Instructions)

1. రిపోజిటరీని GitHub కు Push చేయండి:
   ```sh
   git init
   git add .
   git commit -m "తెలుగు మార్కెట్ పల్స్ — initial commit"
   git remote add origin https://github.com/nithin1024/news-pulse.git
   git branch -M main
   git push -u origin main
   ```
2. రిపోజిటరీ **Settings** → **Secrets and variables** → **Actions** లో `GROQ_API_KEY` సీక్రెట్ను జోడించండి (Groq కన్సోల్ `console.groq.com` నుండి ఉచిత కీని పొందవచ్చు).
3. **Settings** → **Pages** కు వెళ్లి, **Source** ను `GitHub Actions` గా ఎంచుకోండి.
4. **Actions** ట్యాబ్లోని `Collect & publish` వర్క్ఫ్లోను మ్యాన్యువల్గా రన్ చేయండి. ఆ తర్వాత ప్రతి రెండు గంటలకు ఒకసారి ఆటోమేటిక్గా నడుస్తుంది.
